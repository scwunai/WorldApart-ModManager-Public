## 三、结论

1. 官方接口即字节游戏网关 `a1-ovs-prod-external-auth2.bytedgame.com` 的 OpenAI 兼容 `/a1/chat/completions`，后端模型为豆包 `doubao-1.5-pro`。
2. 官方模式不需要、也不接受本地 apiKey —— 用 Steam 登录换取的 JWT 访问令牌鉴权。
3. 因此本地自定义接口（settings.json 的 ainpc 段）无法"伪装成官方通道"，但可以用任何 OpenAI 兼容服务替换整个后端。
4. 官方模式每次对话都上传：完整角色设定 + 对话历史 + 你的角色名/设备信息，注重隐私的话可在设置中切换自定义模式。
