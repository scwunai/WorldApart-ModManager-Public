# 《不问凡尘》MOD 环境 — 对方设备卡死排查手册（agent 执行版）

> 场景：这台设备上，用 MOD 环境启动《不问凡尘》(WorldApart) 后，**厂商 logo 放完黑屏卡死**。
> 你的任务：按第 1～4 步执行对照实验、采集证据，产出一份报告（第 5 步）。
> 铁律：**只读、只复制，不修改/不删除游戏目录里的任何文件**；进程只杀你自己启动的；所有采集的文件副本放进 `%USERPROFILE%\Desktop\MOD排查\`。

---

## 0. 环境确认（先做完再动手）

1. 确认游戏目录（后文记为 `<G>`），典型值：
   `C:\Program Files (x86)\Steam\steamapps\common\<游戏目录>`
   判据：目录下存在 `WorldApart.exe`、`WorldApart_Data\`、`UnityPlayer.dll`。
2. 确认 MOD 组件已部署：`<G>` 下应存在 `modlauncher.exe`、`modprobe.dll`、`inject.ini`、`WorldApart_mod.exe`、`WorldApart_mod_Data`（联接）、`启动MOD版.bat`、`BepInEx\`。
   缺哪几个，原样记进报告（这本身就是线索）。
3. 建采集目录：`mkdir %USERPROFILE%\Desktop\MOD排查`

## 1. 证据采集（每次实验后都跑一遍）

把下列文件**复制**（不要移动）到 `%USERPROFILE%\Desktop\MOD排查\<实验名>\`：

| 文件 | 位置 | 说明 |
|---|---|---|
| `mod_inject.log` | `<G>` | 启动器日志（UTF-16，打不开就用 PowerShell `Get-Content` 读） |
| `modprobe.txt` | `<G>` | 注入器日志（含 WATCH 心跳行） |
| `LogOutput.log` | `<G>\BepInEx` | BepInEx 主日志 |
| `ErrorLog.log` | `<G>` | 游戏错误日志 |
| `Player.log` / `Player-prev.log` | `%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart` | Unity 引擎日志，黑屏原因的第一手证据 |

每次实验后记下：**实验开始时间、结束时间、观察到的现象**（logo 后黑屏多久、有无声音、能否 Alt+F4 退出）。

## 2. 对照实验（按顺序，每步之间间隔 10 秒）

### 实验 A：原版基线
- Steam 客户端点"开始"（或双击 `<G>\WorldApart.exe`）。
- 观察能否进主菜单。能进 → 记"基线正常"；也卡死 → 记"原版同样卡死"（那就是机器/游戏本身问题，与 MOD 无关，直接跳到第 5 步写报告）。
- 结束后把 `Player.log` 复制归档。

### 实验 B：免注入对照（最关键的一步）
- 确保游戏完全退出后，**直接双击 `<G>\WorldApart_mod.exe`**。
- 这是原 exe 的硬链接，双击**不会注入任何 MOD 组件**，等价于"换了名字的纯净版"。
- 观察：能进主菜单 / 卡 logo 后黑屏 / 其他。
- 用 cmd 检查联接是否有效：`dir /al "<G>"` 应看到 `WorldApart_mod_Data` 是 JUNCTION 指向 `WorldApart_Data`；再执行 `fsutil reparsepoint query "<G>\WorldApart_mod_Data"` 记录输出。
- 结果归档（含 Player.log）。

### 实验 C：MOD 版启动（复现卡死 + 抓现场）
- 双击 `<G>\启动MOD版.bat`（如黑框一闪而过或无反应，改在 cmd 里执行 `<G>\modlauncher.exe "<G>\WorldApart.exe"` 并记录输出）。
- 黑屏出现后**不要立刻杀进程**，先做两件事：
  1. **CPU 采样**：PowerShell 执行 3 轮，每轮间隔 10 秒：
     `Get-Process WorldApart_mod -ErrorAction SilentlyContinue | Select-Object Id,CPU,WorkingSet,Responding`
     （`CPU` 列若在持续增长 = 还在加载/生成，等满 3 分钟再看；始终为 0 且 `Responding=False` = 死锁）
  2. **线程栈**（需要管理员 PowerShell，拿不到就跳过）：
     `Get-Process WorldApart_mod | ForEach-Object { $_.Threads | Sort-Object TotalProcessorTime -Descending | Select-Object -First 5 Id,TotalProcessorTime,ThreadState }`
- 满 3 分钟后若仍黑屏：先按 Alt+F4 / Esc 看有无反应，再用任务管理器结束 `WorldApart_mod.exe`。
- 全部日志归档。特别看 `modprobe.txt` 最后的 WATCH 行：`done=1` 表示注入侧已完成；`done=0` 且不再增长表示注入侧卡住。

### 实验 D（可选，仅当 C 卡住且 B 正常）：缩小到 BepInEx
- 临时禁用插件：把 `<G>\BepInEx\plugins` 重命名为 `plugins.off`（**实验完必须改回来**），重复实验 C。
- 若禁用插件后不卡了 → MOD 管理器插件嫌疑大；若仍卡 → 注入链/BepInEx 本体嫌疑大。
- 归档后**立即恢复目录名**。

## 3. 清单核对

在报告里逐项打勾（存在/不存在）：
`<G>` 下：`modlauncher.exe`、`modprobe.dll`、`inject.ini`、`doorstop_config.ini`、`启动MOD版.bat`（应为 298 字节左右）、`WorldApart_mod.exe`、`WorldApart_mod_Data`（联接）、`BepInEx\interop\`（约 154 个 dll）
`%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart\Mods\example.tutorial` 是否存在。

## 4. 常见问题速查

- `启动MOD版.bat` 双击没反应 → 用 cmd 执行 `<G>\modlauncher.exe "<G>\WorldApart.exe"` 看输出；并检查 `mod_inject.log` 最后一条是 `LAUNCHER:` 什么内容（`no target exe given` = 参数没传进去；`FAIL: spawn helper` = 启动器组件旧，需用 v1.4 重跑安装）。
- `inject.ini` 里的 `dll=` 路径必须与 `<G>\modprobe.dll` 实际位置一致，且**整行不要带引号**。
- 首次启动黑屏 1 分钟左右属正常（生成兼容层）；v1.4 包已预置兼容层，正常应秒进。
