# 教程示例 MOD：人物口吻与档案

这是**第一个 MOD 的最佳起点**。包内每一步都是独立的 unit，可在 设置 → MOD管理 里单独开关。

## 这个包改了什么

| Unit | 修改目标 | 效果 |
|---|---|---|
| `step1_persona` | `tbnpcaipersona`（NPC 说话风格表） | 苏倾盏（npcId 100000）的 AI 说话风格变为豪爽江湖口吻，自称"老娘" |
| `step2_profile` | `tbnpcbasecfg`（NPC 基础配置表） | 苏倾盏的人物档案（propPlot）显示一段教程示例文本 |

启用后：打开苏倾盏的档案页可看到档案变化；与她对话可体验口吻变化。
两处文本都带【教程示例】前缀，方便确认 MOD 生效、也方便还原时辨认。

## 文件结构对照

```
example.tutorial\
  mod.json                                 ← 清单：modId / title / units / defaultEnabled
  step1_persona\tables\tbnpcaipersona.patch.json
  step2_profile\tables\tbnpcbasecfg.patch.json
```

注意 `units[].root` 指向的目录里**必须直接再有 `tables\`**：
游戏实际扫描的是 `<root>\tables\*.patch.json`。root 写错（比如多拼一层 `tables`）时
**没有任何报错，补丁就是不生效**——这是新人最常见的坑。

## 补丁 JSON 三要素

```json
{
  "keyFields": ["npcId"],
  "upsert": [ { "npcId": 100000, "speakStyle": { ... } } ],
  "remove": []
}
```

- `keyFields`：这张表的主键。`tbnpcaipersona` 用 `npcId`，`tbnpcbasecfg` 用 `id`。
- `upsert`：按主键**有则改、无则增**。只写你想改的字段即可，其他字段保持原值。
- `remove`：按主键删除行，一般留空。例：`"remove": [{ "npcId": 100000 }]`
  （教程包别这么干，会删掉苏倾盏的人格配置）。

## 多语言字段

`speakStyle`、`propPlot` 这类 `L10nText` 字段必须给 `zh-Hans` / `zh-Hant` / `en-US` 三个语种，
只写简体会在繁体/英文客户端显示空值。

## 改成你自己的 MOD

1. 复制整个 `example.tutorial` 文件夹，改名（文件夹名随意）
2. 改 `mod.json`：`modId` 换成 `你的名字.包名`（本地测试加 `local.` 前缀）
3. 改补丁里的 `npcId` / 字段 / 文本 → 常见人物与位置 ID 见包内 `常见ID速查表.md`
4. 把文件夹放进 `%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart\Mods\`
5. 启动游戏 → 设置 → MOD管理 → 启用 → 进游戏验证

全表清单（259 张表）可用 `剧情查看器工具` 剧情查看器浏览，或直接在
`配置表解包文件（assets_luban_data_<表名>.json）` 查原始数据。
