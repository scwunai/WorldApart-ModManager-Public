> 数据来源：游戏配置表全量解包（`配置表解包目录（m1_out）\`，259 张表）。
> 想查任意 ID：直接打开 `配置表解包目录（m1_out）\assets_luban_data_<表名>.json` 搜索；
> 或用 `剧情查看器工具（story_editor）` 剧情查看器（剧情脉络图 / 人物 / 视频库三个页签）浏览。

## 1. 位置（空间）ID —— tbspace.id

空间 ID 的编号规律：**城镇主空间是整百号（100、120、130…），镇内子空间是 `城镇号×100+序号`**
（河望镇 100 → 客栈大堂 10001、纪宅 10010；砚州 120 → 城主府 12003…）。

同名空间会有多个 ID（剧情不同阶段的不同状态，如客栈大堂 10001/10005/10006/10009），
做剧情跳跃前请先存档。

## 3. 剧情 / 任务 ID

| 表 | 主键 | 内容 | 规模 |
|---|---|---|---|
| tbquest | id | 任务/剧情节点（name 为任务名） | 1875 条 |
| tbgameactionflow | id | 游戏行动流（剧情跳转真正落地的对象） | 见 m1_out |
| tbdialogue | id | 对话 | 见 m1_out |
| tbstorychase | id | 剧情追逐段 | 见 m1_out |

主线开头示例：1001 初到河望镇、1002 客栈歇脚、11123 客栈落脚、11124 上等的食材、
11125 山腰惊变、11126 返栈疗伤、11117 少女芊儿、11118 功法傍身……

**剧情跳跃建议用 `tbgameactionflow.id`**：它是游戏执行剧情的最小单元，
tbquest 的 objectives 与 tbdialogue 最终都挂接到 flow 上（关联关系见剧情查看器的脉络图）。
