# 《不问凡尘》(World Apart) MOD 环境 — 安装说明

## 这个包是什么

- **BepInEx**（IL2CPP / CoreCLR 版，be.788）+ **MOD 管理器插件**：在游戏内 设置 → MOD管理 页面管理 MOD 启停
- **modlauncher / modprobe**：启动注入组件。游戏使用 gpShell 保护，标准 doorstop 无法自行注入，需经本启动器拉起 MOD 版进程
- **示例 MOD** `example.tutorial`（教程示例：人物口吻与档案）：手把手演示表补丁写法，附包内教程，**默认关闭**

## 安装

1. 把本包**整个文件夹**放到游戏目录下（与 `WorldApart.exe` 同级），或任意位置（安装脚本会询问游戏路径）
2. 运行 `安装_MOD环境.bat`
3. 安装脚本会：
   - 复制 `modlauncher.exe` / `modprobe.dll` / `doorstop_config.ini` / `inject.ini` 到游戏目录
   - 创建 `WorldApart_mod.exe`（指向原 exe 的硬链接）与 `WorldApart_mod_Data`（指向 `WorldApart_Data` 的联接）
   - 复制 `BepInEx\` 与 `dotnet\` 到游戏目录
   - 把示例 MOD 复制到 `%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart\Mods\`
   - 在游戏目录生成 `启动MOD版.bat`
   - 创建 `steam_appid.txt`（内容 `4209920`）：MOD 版经启动器拉起时脱离 Steam 客户端，靠它初始化 SteamAPI；**勿删**，否则 logo 后游戏会自行退出甚至黑屏死锁

## 启动

- **用游戏目录下的 `启动MOD版.bat` 启动**。直接点 Steam 的"开始"仍是原版（无 MOD），两者互不影响
- 本包已预置 IL2CPP 兼容层，正常情况下秒进游戏；**若游戏更新导致兼容层重建，首次启动会黑屏约 1 分钟，属正常现象，仅此一次**
- 想从 Steam 直接进 MOD 版：Steam → 游戏属性 → 启动选项填：
  `"<游戏目录>\modlauncher.exe" "%COMMAND%"`

## 使用

- 游戏内 **设置 → MOD管理**：包级总开关 + 每个 unit 独立开关；点包行可展开/收起
- **F10**：BepInEx 调试窗口（插件作者用）
- 日志：`BepInEx\LogOutput.log`

## 卸载

运行 `卸载_MOD环境.bat`（保留 BepInEx/dotnet/MOD 包，方便以后再用；需彻底删除可手动删游戏目录下的 `BepInEx`、`dotnet`）

## 注意事项

- **游戏更新后**：更新会替换 `WorldApart.exe`，请重跑 `安装_MOD环境.bat` 重建硬链接
- MOD 启用状态保存在注册表，与存档无关；禁用全部 MOD 即还原原版体验
- 详见 `MOD开发文档.md`
