# 给实施模型的指令（MOD 页滚动修复）

这是独立任务，与任何在途线路无关。请阅读 `<G>\KIMI\MOD页滚动修复_实施计划.md` 并严格按其实施。要点重申：

1. **先侦察后动手**：R1 必须拿到滚轮转标签的确切方法（类名+RVA+调用链）再写 F2；R2 确认 Viewport 裁剪组件存在与否再写 F1 的 mask 逻辑。侦察证据（日志/反汇编/调用栈）写进报告。
2. **F1 行堆叠数学零改动**：只把行的父节点换成新 Content 容器，Relayout 的坐标计算一行都不许动（收起/展开行为已验收过，动了必回退）。
3. **F2 只挡滚轮、不挡点击**：点击原生标签关闭 MOD 页是既有验收过的行为，必须保持。
4. 实施报告按验收标准 A1–A7 逐项给证据，报告放 `KIMI\MOD页滚动修复_实施报告.md`；做不到的项目如实标注"未达成"并说明原因，不要掩饰。
5. 部署纪律：只更新 `BepInEx\plugins\LocalModManager.dll`，先备份到 `KIMI\backup_deployed_pre_scrollfix.dll`；不改游戏目录其他任何文件；用户可见字符串/日志/文件名零 kimi。
6. 完成后保持游戏进程处于 MOD 页可测状态（造好 A1 的假包），通知委托方进游戏验收 A2/A4/A5（截图）。
