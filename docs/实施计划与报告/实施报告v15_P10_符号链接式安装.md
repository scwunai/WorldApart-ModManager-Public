| # | 验证项 | 结论 | 关键命令 / 证据（原文见 `result.txt`） |
|---|---|---|---|
| 1 | 目录联接 `mklink /J` | **可行，免管理员** | `mklink /J "<沙箱>\link_to_pack" "<v14.2 包目录>"` → `rc=0`（本进程非管理员）；`dir /a` 显示 `<JUNCTION>`、reparse tag `0xA0000003`；透过链接读 `BepInEx\plugins\LocalModManager.dll` → MD5 `0ee671c2c5bcc63b31c349761881c351` **与源一致**；透过链接 `walk` 472/472 文件 |
| 2 | 目录符号链接 `mklink /D` | **本机不可行** | `mklink /D …` → `rc=1`「你没有足够的权限执行此操作。」（`ERROR_PRIVILEGE_NOT_HELD`）—— 需管理员或开发者模式 |
| 3 | 文件硬链接 `mklink /H` | **同卷可行；跨卷不可行** | 同卷 `rc=0`，往源文件 append 后链接侧字节**同步变化**（同一份数据，`fsutil hardlink list` 两侧互列）；跨卷（源在真实 D: 卷、链接在 C: 卷）→ `rc=1`「系统无法将文件移到不同的磁盘驱动器。」 |
| 4 | 工坊更新语义 | **原地改即时跟随；换路径会悬空** | 源目录原地**改**/源**删**文件/源**增**文件 → 链接侧全部 `FOLLOWED`；整个源目录被删 → 联接悬空（`dir` `rc=1`），在**原路径**重建后又恢复可用（联接按路径解析）；源目录**改名/换到新路径** → 联接**悬空失效**。卸载：`rmdir "<link>"`（不带 `/s`）→ 链接消失、**源内容无损**；对照组 `rmdir /s /q "<link>"` 本机实测**也只摘联接、不递归删源**（比预期安全，仍按最保守做法实现脚本） |
| 5 | 跨卷判定 | **联接不要求同卷；但不能指网络路径** | 卷 GUID 实测：`<G>` 其实**是指向** `<G>（真实路径）` 的**联接**，真实落在 **C: 卷** `\\?\Volume{34142781-efa4-44a2-be85-6290dc979334}\`；而 `<Steam库>\steamapps\workshop` 是真实 **D: 卷** `\\?\Volume{36ce0688-d97f-4822-ae2c-13bb2774d716}\` ——**两者不同卷**（与委托前提「<G> 与 Steam 库同一卷」不符，但**不影响方案**）。跨卷 `mklink /J`（链接在 C:、目标在真实 D:）→ `rc=0`、可读可列；指向网络驱动器 `Y:\` → `rc=1`「完成该操作需要本地卷。」|

**总判定：可行**（本机非管理员环境下，目录联接完全满足「工坊更新后免重装」）。成立条件 / 边界：
① 联接 `mklink /J` **免管理员、免开发者模式**（实测）；② **不要求同卷**（实测跨本地卷可用）；
③ 联接目标必须是**本地**路径，网络路径不可；④ 只有退而求其次的 `/D` 符号链接才需要管理员/开发者模式；
⑤ Steam 若把内容目录**整体改名/换到新路径**，联接悬空 —— 重跑安装脚本即恢复；⑥ 卸载用**不带 `/s` 的 `rmdir`**。

**踩到的坑（已写进脚本注释）**：把整条命令当一个 argv 交给 `cmd.exe /c`
（`subprocess.run(['cmd.exe','/c','mklink /J "a" "b"'])`）会被 cmd 的引号剥离规则弄坏 → 报「文件名、目录名或卷标语法不正确」(123)；
必须 `shell=True` 或把参数分开传。

**自测暴露并修掉的三个真 bug**（都已修、都已被断言覆盖）：
1. `echo … -> …` 里的 `->` 被 cmd 当作**重定向运算符**（输出被吞掉，还去写源目录 → 「拒绝访问」）；
2. `if … ( … )` 块内的 `echo` 文本里出现**半角括号**（或 `%VAR%` 展开出 `(x86)`）会打乱括号配对，
   导致 `else` 分支被误执行 → 块内一律全角括号 + 延时展开 `!VAR!`；
3. 源 == 目标时的**自指联接**会建成死循环 → 加保护（D 态）。

### 边界与回退策略（同步写进包内 `安装说明.md`）

* 逐项回退顺序 `mklink /J` → `mklink /D` → `robocopy /e /xo`，并把 `/J`、`/D` 的**报错原文**打印在那一项下面；
* 建成联接后**再做一次「透过链接能否读到源内容」的校验**（`:alink_ok`），防止"联接建成功但读不到"被误报为安装成功；
* 内容目录 == 游戏目录（自指）→ 不建联接，按「已在位」处理；
* 游戏目录里已有真实目录占位 → 先试非递归 `rmdir`（空目录或联接会被摘掉），仍占位则改名 `.bak_<rand>` 保留后再挂；
* 卸载只摘链接：先 `fsutil reparsepoint query` 判定是不是联接，再用**不带 `/s` 的 `rmdir`**；游戏目录里的 `BepInEx\`/`dotnet\` 与 Mods 示例 MOD 都查。
